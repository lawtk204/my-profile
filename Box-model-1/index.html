```html Sử dụng Box Model 1

Sử dụng Box Model trong CSS

So sánh box-sizing: content-box và border-box

Thẻ thứ nhất

box-sizing: content-box

Chiều rộng và chiều cao chưa tính padding và border.

Thẻ thứ hai

box-sizing: border-box

Chiều rộng và chiều cao đã bao gồm padding và border.

Thẻ thứ ba

box-sizing: border-box

Thẻ có nền đỏ để dễ phân biệt.

```
